# sally-voice｜宋琼的口吻

帮助同事用宋琼（Sally）的表达风格，撰写和修改视频号口播稿，也可用于文章及演讲草稿。

核心表达方式：从真实疑问进入，用具体场景解释机制，给出清楚判断，再落到人的选择与行动。保留口语的自然连接与长短变化，不固定套用金句开场、排比和升华结尾。

## 安装到 Codex

把下面这句话发给 Codex：

> 请用 skill-installer 安装 https://github.com/sallysong0509/sally-voice 仓库根目录的 Skill，安装名称为 sally-voice（仓库路径为 .）。

安装成功后，在下一轮对话中使用 `$sally-voice`。

也可以在已安装 Git 的 macOS / Linux 终端执行：

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
git clone https://github.com/sallysong0509/sally-voice.git "${CODEX_HOME:-$HOME/.codex}/skills/sally-voice"
```

如果目标目录已经存在，先保留已有修改，不要直接覆盖。通过 Git 安装的副本可在工作区干净时用 `git pull --ff-only` 更新。

## 使用示例

```text
请用 $sally-voice，按宋琼的口吻写一篇面向家长的口播稿。

主题：孩子提出换兴趣班时，先理解原因。
核心观点：不能立刻认定他缺乏毅力，应区分遇到困难与兴趣发生变化。
素材：只有上述观点，没有真实家庭故事。
篇幅：300字以内。
要求：平实自然，不加报名邀请，不编造亲历故事。
```

日常只需要给主题和素材；听众、时长、必须保留的原话以及是否需要活动邀请，都可按当次需要补充。

## 文件

- `SKILL.md`：触发范围、写作方法、声口规则与交付检查。
- `references/voice-evidence.md`：八维风格观察、必要短句及迁移方法。
- `agents/openai.yaml`：Codex 中的名称和默认调用提示。

全部文风指导随包提供，不需要登录私人飞书文档，不需要 API Key 或另装依赖。本仓库是 Skill 文件包，不是浏览器插件，也不包含模型微调或声音克隆功能。

## 使用范围与校准

欢迎同事安装并用于稿件起草。生成稿不等于宋琼本人已经认可，发布前仍按团队原有审稿流程确认。请使用有依据的事实、经历与项目数据；风格迁移不会替代事实核验。

v0.1.0，2026-10-28。依据本人指定材料形成，声口会通过实际稿件反馈继续校准。对某一篇稿件的修改不自动变成所有稿件的固定规则。
